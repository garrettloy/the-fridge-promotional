# The Fridge: promotional page

A one-page tour of The Fridge, an offline, pen-first learning app for kids in kindergarten through
5th grade with a PIN-locked parent dashboard. The app's code lives in a separate private repository;
this repository holds only the page.

**Live page: https://garrettloy.github.io/the-fridge-promotional/**

- `index.html`: the page (no build step; fonts load from Google Fonts)
- `img/`: screenshots from a Pixel Tablet, status bar cropped

Served with GitHub Pages from the `main` branch.
